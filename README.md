## 🧰 JCTechStudio Tools

**Auditoría web + herramientas de Inteligencia Artificial**

Aplicación web que reúne herramientas de análisis y productividad digital.

Incluye auditoría web basada en **Lighthouse**, comparación de resultados
móvil/desktop, análisis de rendimiento, accesibilidad, SEO y buenas prácticas,
recomendaciones de mejora y generación de informes.

También incorpora herramientas de IA para trabajar con texto, generar emails,
crear contenido para redes sociales, traducir y utilizar un asistente conversacional.
